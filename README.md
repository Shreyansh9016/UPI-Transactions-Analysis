<h1>📊 UPI Transaction Analysis</h1>

<p>
This repository contains an analysis of <b>UPI transactions</b> using both raw data and interactive visualizations. 
The project is designed to explore transaction trends, balances, and city-level insights through 
<b>Power BI dashboards</b>, supporting files, and reports.
</p>

<hr/>

<h2>📂 Repository Contents</h2>
<ul>
  <li><b>Report PDF</b> → A compiled PDF report summarizing the insights and dashboards.</li>
  <li><b>Power BI File (.pbix)</b> → Interactive Power BI dashboard for detailed exploration.</li>
  <li><b>Dataset</b> → Raw data used for the analysis of UPI transactions.</li>
  <li><b>Images (5)</b> → Exported visuals/screenshots from the dashboard for quick viewing.</li>
</ul>

<hr/>

<h2>📈 Dashboard Overview</h2>
<p>The Power BI report is divided into <b>two main pages</b>:</p>

<h3>🔹 Page 1 – Monthly Insights</h3>
<p>This page contains <b>four key charts</b> to visualize balance and transaction trends:</p>
<ul>
  <li><b>Balance by Month (Line Chart)</b> – Displays how the account balance has fluctuated over time.</li>
  <li><b>Balance by Month (Column Chart)</b> – Reinforces the line chart with a bar perspective for comparative clarity.</li>
  <li><b>Transactions by Month (Line Chart)</b> – Shows transaction volume trends month over month.</li>
  <li><b>Transactions by Month (Column Chart)</b> – Provides a bar view to compare transaction volumes across months.</li>
</ul>

<p>👉 <b>Slicers/Scalers</b> are included to filter data dynamically, allowing users to interact with the dashboard by selecting specific months, time ranges, or other categories.</p>

<h3>🔹 Page 2 – City-Wise Analysis</h3>
<p>This page focuses on a <b>matrix view</b> that enables city-level drilldown analysis:</p>
<ul>
  <li><b>Rows</b> → Cities</li>
  <li><b>Columns</b> → Months and Cities</li>
  <li><b>Values</b> → Transaction Amounts and Remaining Balances</li>
</ul>

<p>📌 <b>Note:</b> Page 2 is <b>linked with Page 1 filters</b>. Any filters applied on Page 1 (e.g., specific months or time ranges) are automatically reflected on Page 2 for a seamless analytical experience.</p>
